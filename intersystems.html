Desarrollo sobre InterSystems IRIS

Implementación, interoperabilidad y desarrollo asistido por IA sobre la plataforma de datos y salud digital más adoptada en Chile y Latinoamérica.

Por qué InterSystems IRIS

La plataforma detrás de los sistemas de salud más exigentes

InterSystems IRIS for Health y HealthShare son la columna vertebral de hospitales, clínicas y redes de salud en más de 80 países. Su arquitectura unificada permite gestionar datos, procesos, analítica e interoperabilidad en una sola plataforma.

Combinamos más de 20 años de experiencia en transformación digital en salud con desarrollo activo sobre IRIS: desde Interoperability Productions y FHIR R4, hasta modelos predictivos con IntegratedML y agentes conversacionales con LLM.

Capacidades

Qué podemos construir sobre IRIS

Interoperabilidad clínica y empresarial

Diseño e implementación de Interoperability Productions que conectan sistemas heterogéneos con lógica de negocio robusta.

  • FHIR R4: Patient, Appointment, Organization, Schedule, Location.
  • Integración SAP (BAPI, JDBC, RFC): usuarios, facturación, glosas, cartera.
  • Conectores VTEX y otras plataformas de e-commerce mediante webhooks REST.
  • Bases de datos heterogéneas: MySQL, PostgreSQL vía JDBC/ODBC.
  • Procesamiento automático de archivos CSV con monitor de filesystem.

IA aplicada: IntegratedML y LLM

Modelos predictivos nativos en IRIS y asistentes conversacionales que consultan datos clínicos y de gestión.

  • IntegratedML para predicción clínica (no-shows, uso de recursos, riesgo).
  • BI conversacional: preguntas en lenguaje natural → MDX → cubos IRIS.
  • Integración con Claude API, OpenAI y NVIDIA AgentIQ.
  • Agentes multi-LLM con handoffs, guardrails y trazabilidad.

Orquestación de procesos con BPL

Flujos de integración complejos modelados con Business Process Language, auditables y modificables sin recompilación.

  • Lógica de negocio en BPL: condiciones, loops, llamadas a Operations.
  • Auditoría estructurada por mensaje y por transacción.
  • Manejo de errores, reintentos y alertas.
  • Trazabilidad completa desde ingreso hasta destino final.

Business Intelligence sobre IRIS

Cubos analíticos y reportes consolidados que integran múltiples fuentes de datos clínicos y administrativos.

  • Cubos fact/dimensión sobre datos de SAP, RRHH y sistemas clínicos.
  • MDX y Pivot queries para análisis multidimensional.
  • Consolidación de reportes SAP (facturación, glosas, cartera FI).
  • Governance de acceso y allowlists para consultas desde LLM.

Proyectos concretos sobre IRIS

Cada uno de estos proyectos está implementado y documentado. Pueden servir como base o inspiración para un proyecto en tu organización.

Orquestación VTEX ↔ SAP ↔ Email

Recuperación automatizada de carritos abandonados en empresa retail multipaís. Business Service recibe webhook de VTEX, el Business Process (BPL) evalúa la lógica de negocio y dispara Operations hacia SAP BAPI, MySQL JDBC y correo.

ObjectScript BPL SAP BAPI VTEX MySQL JDBC

BI conversacional con ChatGPT

Asistente que traduce preguntas en lenguaje natural a consultas MDX contra cubos analíticos IRIS. Custom GPT con REST API gobernada por allowlists. Los equipos de gestión consultan reportes sin necesidad de conocer MDX.

OpenAI / Custom GPT REST API MDX / BI Cubes Governance

Predicción de no-shows con IntegratedML + Claude

Modelo predictivo entrenado sobre tablas Patient / Physician / Appointment en IRIS con IntegratedML. FastAPI expone el modelo al exterior; Claude API enriquece las predicciones con contexto conversacional.

IntegratedML Claude API FastAPI HealthCare

Ingesta automática de CSV multibase

Production IRIS con monitor de filesystem que detecta archivos CSV, los procesa mediante un Business Process y los carga en MySQL y PostgreSQL vía ODBC. Diseñado para entornos 24/7 con Docker.

FileService Business Process MySQL PostgreSQL Docker

FHIR R4 sobre IRIS for Health

Aplicación React 19 + TypeScript con CRUD completo de recursos FHIR R4: Patient, Organization, Location, Appointment, Schedule. Conectada al endpoint FHIR nativo de IRIS for Health / HealthShare.

FHIR R4 HealthShare React 19 TypeScript shadcn/ui

Integración SAP: gestión de usuarios

REST API sobre IRIS que expone operaciones de gestión de usuarios en SAP mediante BAPI: listar, crear, bloquear, desbloquear. CSP Pages como interfaz web complementaria. Namespace DEMO con Docker.

IA y agentes

Más allá de IRIS: ecosistema de IA aplicada

Además del desarrollo sobre IRIS, trabajamos con frameworks de agentes y herramientas de IA que pueden complementar o extender las capacidades de la plataforma.

  • OpenAI Agents SDK: flujos multi-agente con handoffs entre especialistas y guardrails de seguridad.
  • NVIDIA AgentIQ: toolkit agnóstico para equipos de agentes, compatible con MCP y UI de chat.
  • Computer Using Agents (CUA): agentes con visión que toman capturas y ejecutan acciones en interfaces.
  • RAG / búsqueda semántica: embeddings sobre datos clínicos y de gestión con Pinecone.
  • Claude API (Anthropic): integración directa en producciones IRIS, FastAPI y backends Python.
  • Prompt caching: reducción de costos en procesos de análisis repetitivo sobre documentos clínicos.
  • Multi-agent con IRIS: IRIS como motor de datos y orquestación; LLM como capa de razonamiento.
